# Password Strength Checker

## Description

This is a Python project that checks the strength of a password based on different security rules.

## Features

* Checks password length
* Checks for uppercase letters
* Checks for lowercase letters
* Checks for numbers
* Checks for special characters
* Displays whether the password is Strong or Weak

## Technologies Used

* Python 3

## How It Works

The program asks the user to enter a password and verifies:

1. Minimum length of 8 characters
2. At least one uppercase letter
3. At least one lowercase letter
4. At least one digit
5. At least one special character

If all conditions are satisfied, the program displays:

Strong Password

Otherwise, it displays:

Weak Password
